# プリセットの編集・追加

`presets.csv` が、アプリの検索候補（自動入力の候補）の**唯一のソース**です。
ここを手で直せば、アプリを使う全員の候補が変わります。

`js/presets.js` は**このファイルから自動生成される**ので、直接編集しないでください。

## いちばん簡単な直し方（iPhone でもできる）

1. GitHub で [`data/presets.csv`](https://github.com/KURU77/travel-wishlist/edit/main/data/presets.csv) を開く
2. 鉛筆アイコンで編集画面に入り、行を足す・直す
3. 「Commit changes」で保存

保存すると GitHub Actions が走り、`js/presets.js` を作り直して自動でコミットします。
数分後には公開サイトの候補に反映されます。**書式に間違いがあると Actions が赤くなり、
何行目の何が悪いか日本語で出ます。** その場合 `presets.js` は作り直されないので、
壊れたデータが公開されることはありません。

手元で直す場合は、CSV を編集してから:

```bash
node tools/build-presets.mjs
```

`--check` を付けると生成せずに書式の検査だけできます。

## 列の意味

| 列 | 必須 | 内容 |
|---|---|---|
| **名称** | ○ | 候補に表示される名前。**重複不可**（重複するとエラー） |
| **検索キー** | | ここに書いた語でも検索に引っかかる。よみ・別名・ローマ字・市区町村などをスペース区切りで。空でも可 |
| **所在地** | | 候補の2行目に出る。日本は **`日本 / 都道府県 市区町村`** の形にすると、エリア別ページで正しく振り分けられる。海外は `イタリア / ローマ` のように国名から |
| **緯度** | ○ | -90〜90 の数値 |
| **経度** | ○ | -180〜180 の数値 |
| **分類** | ○ | 下の一覧から1つ |
| **世界遺産** | | UNESCO世界遺産なら `yes`、違うなら空 |
| **OSM_ID** | | あると、選んだときに営業時間や公式サイトを OpenStreetMap から自動で取ってくる。`N`/`W`/`R` + 数字。無くても可 |

### 分類に使える値

`heritage`（遺跡・史跡） `monument`（建造物・名所） `temple`（寺社・教会）
`castle`（城・宮殿） `museum`（博物館・美術館） `nature`（自然・絶景）
`park`（公園・庭園） `onsen`（温泉） `gourmet`（グルメ）
`activity`（体験・レジャー） `shop`（ショップ・市場） `city`（街・エリア） `other`（その他）

## 行の書き方の例

```csv
名称,検索キー,所在地,緯度,経度,分類,世界遺産,OSM_ID
ラ コリーナ,ラコリーナ 近江八幡 たねや 滋賀県,日本 / 滋賀県 近江八幡市,35.14985,136.0915,monument,,W533308886
中野うどん学校,うどん打ち体験 琴平町 香川県,日本 / 香川県 琴平町,34.18512,133.81653,activity,,
```

- 値に `,` や `"` を含めたいときは、その値全体を `"` で囲み、中の `"` は `""` と2つ重ねる
- 行の順番は自由。アプリ側では入力に対する一致度で並べ替えられる

## 座標と OSM_ID の調べ方

**アプリの開発モードを使うのが一番早い**です。タイトルを7回タップ（または `?dev=1`）→
メニューの「🛠 プリセットを編集」→「＋ 新規」→ 場所名で検索して候補をタップすると、
所在地・座標・分類・OSM_ID が自動で埋まります。そのまま
**「追加・編集分をCSV行でコピー」**を押せば、ここに貼るだけの行が手に入ります。

手で調べるなら:

- 座標 — [openstreetmap.org](https://www.openstreetmap.org/) で右クリック →「ここを表示」、または Google マップで右クリックすると出る `35.681, 139.767` の値
- OSM_ID — openstreetmap.org で対象を選ぶと URL が `/node/123456` のようになる。`node`→`N`、`way`→`W`、`relation`→`R` を付けて `N123456` と書く

## 消したいとき

その行ごと削除してください。すでにその場所を登録している利用者の記録は消えません
（登録データは各自の端末にコピーされているため、候補から消えるだけです）。
