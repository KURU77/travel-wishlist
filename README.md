# 🗺️ 行きたい観光地リスト

行きたい観光地や世界遺産を、**名称・営業時間・所在地（地図つき）**でリスト化できる Web アプリです。
検索窓に名称を入れるだけで、地名・住所・営業時間・座標が自動で入力されます。

iPhone のホーム画面に追加して、アプリのように使うことを想定しています。

## 画面

下のタブで4つの画面を切り替えます。

| 画面 | 内容 |
|---|---|
| **ホーム** | 登録数のサマリー、クイックアクセス（追加・地図・エリア別・世界遺産・計画中・訪問済）、次の訪問予定、優先度の高い場所、エリア／分類から探すチップ、最近追加した場所 |
| **リスト** | 全件のカード表示。フリーワード・状態・分類・世界遺産で絞り込み、4種の並び替え |
| **エリア** | 登録した場所を **地域別（関東・近畿…）／都道府県別／国・地域別** にまとめて表示。グループごとに件数と訪問済数、「この範囲を地図で見る」ボタン付き |
| **地図** | 全ピンを地図に表示 |

ホームのチップやサマリーの数字はすべてタップでき、該当する絞り込み済みのリストやエリアへ直接飛べます。
都道府県は保存済みの所在地から自動で判定するので、以前に登録した場所もそのままエリア別に並びます。

## 主な機能

- **名称を検索して自動入力** — 候補をタップすると名称・所在地・営業時間・公式サイト・座標・世界遺産かどうかが一括で入力されます。検索は3段構え:
  1. **内蔵プリセット**（世界の世界遺産＋日本の全都道府県の観光地・体験施設・グルメ・温泉など）— オフラインでも即座に候補が出ます
  2. **Photon**（OSM を入力補完向けに索引した検索）— 部分入力に強く、「ラコリーナ」だけでもヒット。飲食店や体験施設まで拾えます
  3. **Nominatim** — 住所・地名で取りこぼしを補完
  
  選択後に OSM のタグから営業時間・公式サイト・料金を自動で埋めます
- **所在地を地図で記録** — Leaflet + OpenStreetMap。ダイアログ内の地図をタップ／ピンをドラッグして位置を微調整でき、「現在地」ボタンにも対応
- **地図ビュー** — 登録した全スポットをピンで一覧表示。ピンをタップすると詳細と Google マップへのリンクが出ます
- **管理項目** — 分類／ステータス（行きたい・計画中・訪問済）／優先度／料金／訪問予定日／メモ／UNESCO 世界遺産フラグ
- **分類は自由に編集** — 既定は 遺跡・史跡／建造物・名所／寺社・教会／城・宮殿／博物館・美術館／自然・絶景／公園・庭園／温泉／グルメ／体験・レジャー／ショップ・市場／街・エリア／その他 の13種。メニューの「分類を編集」から、アイコン（絵文字パレット付き）・名前の変更、追加、並べ替え、削除ができます。削除した分類の登録は自動で「その他」に移ります
- **絞り込みと並び替え** — フリーワード、ステータス、分類、世界遺産のみ、追加順・名称順・優先度順・訪問予定日順
- **データはすべて端末内（localStorage）** — サーバー送信なし。JSON で書き出し／読み込みが可能

## オフライン対応

機内モードや電波の届かない場所でも使えます。

- **アプリ本体** — Service Worker が HTML/CSS/JS/アイコンをキャッシュ。オフラインでも起動し、登録・編集・絞り込み・地図表示がそのまま動きます
- **検索** — 内蔵プリセット404件はオフラインでも候補に出ます（オンライン専用の Photon・Nominatim 検索は、つながらない旨を表示して手入力に切り替えられます）
- **地図タイル** — 一度表示した範囲は自動でキャッシュ。さらにメニューの **「地図をオフライン保存」** で、登録済みスポット周辺（ズーム3〜13）と世界地図（ズーム0〜2）をまとめてダウンロードできます
- オフライン中はヘッダーに「オフライン」バッジが出ます

保存した地図タイルはアプリを更新しても消えません（キャッシュ名にバージョンを付けていないため）。

## iPhone での使い方（ホーム画面に追加）

1. Safari で公開 URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. 追加されたアイコンから起動（全画面のスタンドアロン表示になります）

入力時に画面が拡大しないよう、`maximum-scale=1` の指定に加えてフォーム部品の文字サイズを 16px 以上に固定し、ダブルタップ／ピンチによる拡大も抑止しています（地図の中だけはピンチ操作が有効です）。

## ローカルで動かす

`file://` では Service Worker と一部の API が動かないため、簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

## GitHub Pages で公開する

このリポジトリの Settings → Pages → Source を `Deploy from a branch` / `main` / `/ (root)` にすると、
`https://<ユーザー名>.github.io/travel-wishlist/` で公開されます。ビルド不要の静的サイトです。

## 技術メモ

- 依存は同梱の [Leaflet](https://leafletjs.com/) 1.9.4 のみ（`js/vendor/`）。ビルドツール・CDN 不要
- 地名検索は [Photon](https://photon.komoot.io/) と [Nominatim](https://nominatim.openstreetmap.org/) の利用ポリシーに配慮し、入力から 500ms のデバウンス＋同一クエリのキャッシュで通信を抑えています。Nominatim は Photon の結果が3件未満のときだけ引きます
- 内蔵プリセットの国内データは `scripts/` 相当のビルド時に Photon で実座標を解決したものです（手打ちの推定座標ではありません）
- 地図タイルは [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors。タイルを Service Worker でキャッシュできるよう `crossOrigin: 'anonymous'` で取得しています（不透明レスポンスではキャッシュできないため）
- オフライン保存は OSM のタイル利用ポリシーに配慮し、同時接続4本・最大1500枚に制限しています
- アプリを更新したときは `sw.js` の `VERSION` を上げてください（古いキャッシュを破棄して新しい版を配ります）
